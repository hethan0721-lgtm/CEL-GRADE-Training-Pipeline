# Synthetic Tabular Demo Data

All records in this directory are fully synthetic and generated by [`generate_synthetic_data.py`](generate_synthetic_data.py). They are not derived from real patients or clinical records.

The files are provided only to demonstrate and test the text classification pipeline. They must not be used for clinical analysis or scientific conclusions.

## Files

* `synthetic_train.csv`: synthetic data for training and internal evaluation.
* `synthetic_external.csv`: synthetic data for external evaluation.
* `generate_synthetic_data.py`: reproducibly generates both CSV files.

## Data Structure

Each CSV file contains:

* An anonymous synthetic sample identifier
* One categorical model feature
* Four numerical model features
* A binary target indicating whether surgery is required

The exact input fields are defined in [`text_pipeline/src/config.py`](../../text_pipeline/src/config.py). The sample identifier is not used as a model feature.

The files contain no names, identity numbers, medical record numbers, telephone numbers, addresses, or other personally identifiable information.

Some values are intentionally left blank or represented using common numerical signs to exercise the pipeline's data-cleaning and missing-value handling.

## Usage

Generate the demo files:

```bash
python examples/synthetic_tabular_data/generate_synthetic_data.py
```

Run the training pipeline:

```bash
python -m text_pipeline.src.main \
  --mode train \
  --train-data examples/synthetic_tabular_data/synthetic_train.csv \
  --external-data examples/synthetic_tabular_data/synthetic_external.csv
```

The pipeline performs its internal data split, preprocessing, feature transformation, model training, and evaluation using these synthetic records.
