# Synthetic Tabular Demo Data

All records in this directory are fully synthetic and generated by [`generate_synthetic_data.py`](generate_synthetic_data.py). They are not derived from real patients, clinical records, or any identifiable source.

The files are provided only to demonstrate and test the M0_CLIN text/tabular classification pipeline. They must not be used for clinical analysis, clinical decision-making, model performance claims, or scientific conclusions.

## Files

* `synthetic_train.csv`: synthetic data for model training and internal evaluation.
* `synthetic_external.csv`: synthetic data for external evaluation.
* `generate_synthetic_data.py`: reproducibly generates both synthetic CSV files.

## Data Structure

Each CSV file contains nine columns:

* One anonymous synthetic sample identifier
* Five numerical model features
* Two categorical model features
* One binary target indicating whether surgery is required

The columns are:

| Type                | Column name        | Description                                                                   |
| ------------------- | ------------------ | ----------------------------------------------------------------------------- |
| Identifier          | `sample_id`        | Anonymous synthetic sample identifier; excluded from the model feature matrix |
| Numerical feature   | `矫正视力`             | Corrected visual acuity                                                       |
| Numerical feature   | `矫正球镜度数(D)`        | Corrected spherical power in diopters                                         |
| Numerical feature   | `矫正柱镜度数(D)`        | Corrected cylindrical power in diopters                                       |
| Numerical feature   | `IOLMaster-Cyl(D)` | IOLMaster cylinder power in diopters                                          |
| Numerical feature   | `年龄`               | Age                                                                           |
| Categorical feature | `是否配合检查`           | Cooperation with examination; synthetic values are `是` and `否`                |
| Categorical feature | `脱位程度`             | Dislocation severity; synthetic values are `轻`, `中`, and `重`                  |
| Target              | `是否需要手术`           | Binary outcome; `不手术` is encoded as 0 and `手术` as 1                           |

The seven model features are defined in the following fixed model-input order in [`text_pipeline/src/config.py`](../../text_pipeline/src/config.py):

1. `矫正视力`
2. `矫正球镜度数(D)`
3. `矫正柱镜度数(D)`
4. `IOLMaster-Cyl(D)`
5. `年龄`
6. `是否配合检查`
7. `脱位程度`

The input CSV columns are selected by their machine-readable column names. The pipeline then places the seven model features into the fixed order defined by `Config.FEATURE_COLUMNS`. The `sample_id` column is retained only as an anonymous synthetic identifier and never enters the model feature matrix.

The synthetic age distribution, cooperation distribution, feature values, and target labels are illustrative placeholders generated only to exercise the software pipeline. They do not represent any real clinical population or medically validated relationship.

The files contain no patient or clinician names, identity numbers, medical record numbers, telephone numbers, addresses, or other personally identifiable information.

Some numerical and categorical values are intentionally left blank. Some numerical values also contain common formatting artifacts, such as trailing signs or full-width minus symbols. These values are included to exercise the pipeline’s data-cleaning, missing-value handling, preprocessing, and validation behavior.

## Usage

Generate or regenerate the synthetic files:

```bash
python examples/synthetic_tabular_data/generate_synthetic_data.py
```

Run the training pipeline using the generated files:

```bash
python -m text_pipeline.src.main \
  --mode train \
  --input-data examples/synthetic_tabular_data/synthetic_train.csv \
  --external-data examples/synthetic_tabular_data/synthetic_external.csv
```

The pipeline performs:

1. Input loading and data cleaning
2. Stratified internal train-test splitting
3. Feature preprocessing
4. Training-only SMOTE resampling
5. XGBoost model training
6. Five-fold cross-validation
7. Internal test evaluation
8. External evaluation

The internal test partition and synthetic external dataset are used only for post-training evaluation. Neither dataset is passed to the final classifier’s `.fit()` call.

All outputs produced from these synthetic files are demonstration results only and must not be interpreted as estimates of clinical performance.
